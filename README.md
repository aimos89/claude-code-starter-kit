## Quick start
1. Copy the `CLAUDE.md` template into your project root, delete what doesn't apply, fill the blanks.
2. Copy `commands/commit.md` into `.claude/commands/` (repo) or `~/.claude/commands/` (global) → `/commit`.
3. Skim `GUIDE.md` once.
